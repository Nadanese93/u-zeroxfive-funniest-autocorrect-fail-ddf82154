One line under 200 characters that reads as a hilarious autocorrect fail: a text to a girlfriend asking for a hug, turned by autocorrect into a request for a thug. The program writes the fail to `entry.txt`.

> I texted my girlfriend 'I need a hug' — autocorrect sent 'I need a thug.'

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
